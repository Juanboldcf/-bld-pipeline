Pixel Agents no está corriendo

Pixel Agents (open-source, MIT, sin costo) convierte tus sesiones de Claude Code en personajes pixel art que caminan, se sientan y escriben en una oficina. La Oficina BLD lo muestra aquí cuando está activo. Es complementario: esta app sabe de tus proyectos y agentes BLD; Pixel Agents ve cada sesión de Claude Code (incluidos los sub-agentes).

Opción A · navegador (recomendada). En una terminal, en solo lectura y solo en tu máquina:

ASDF_NODEJS_VERSION=$(asdf latest nodejs 22) npx -y pixel-agents --host 127.0.0.1 --port 3100 --no-terminal

Necesita Node 22 o superior (una dependencia no corre con Node 20). Con asdf: asdf install nodejs latest:22 una sola vez; el comando de arriba lo usa solo para esta ejecución.

Opción B · VS Code. Instala la extensión desde el Marketplace y abre el panel «Pixel Agents» junto a la terminal.

  • No actives «hooks» desde su configuración: editarían tu ~/.claude/settings.json. Sin hooks igual detecta las sesiones leyendo las transcripciones.
  • La Oficina BLD no guarda nada de esto en Bold Brain.
